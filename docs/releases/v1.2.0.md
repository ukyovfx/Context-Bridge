# Context Bridge v1.2.0

## Highlights

- Windows-first per-user installer with safe PATH management and data-preserving uninstall.
- Machine-local setup with optional Codex global bootstrap and read-only diagnostics.
- Local-first `new`, conservative existing-repository `integrate`, and ChatGPT Project bootstrap output.
- Guarded registry/workspace identity, manifest provenance, migration plans, and deterministic release artifacts.

## Distribution

- Windows installer: `contextbridge-v1.2.0-windows-amd64-setup.exe`
- Windows portable ZIP: `contextbridge-v1.2.0-windows-amd64.zip`
- Linux archive: `contextbridge-v1.2.0-linux-amd64.tar.gz`
- `SHA256SUMS` and `release-manifest.json`

The installer is unsigned because no release signing identity is configured.
Verify the published SHA-256 checksums before installation.

## Known limitations

- Hosted GitHub Actions verification is currently blocked by the repository account billing/spending-limit issue.
- No self-updater, winget package, MCP, daemon, GUI, or model/API integration is included.
- External tools can still write outside Context Bridge’s guarded mutation paths.
